● v0.1 — Daytona HackSprint build

Every repository deserves a Try button.

Paste a public GitHub URL. Try SDK clones it into an isolated Daytona sandbox, runs npm ci, starts the repo's own dev server, and gives you a live preview link you can share — before you clone anything.

Works with Vite projects — React, Vue, Svelte, Solid, vanilla JS. Sandboxes are isolated and destroy themselves when abandoned.

Real repository code
